# FrameNest
A free static TikTok comparison workspace. Open index.html to use locally, or host on GitHub Pages. No packages, build step, API keys, or paid backend.

## Publish free on GitHub Pages
1. Create a free GitHub account and verify your email.
2. Create a public repository named framenest.
3. Upload index.html, style.css, app.js, and .nojekyll to the repository root and commit.
4. Open Settings → Pages → Build and deployment. Choose Deploy from a branch, main, /(root), and Save.
5. GitHub supplies https://YOUR-USERNAME.github.io/framenest/ after deployment completes.

Use the supplied github.io address to avoid buying a domain. GitHub hosting policies and limits apply. Account verification must be completed by the account owner.

## Notes
- Public full TikTok video URLs only; short-link resolution would need an additional service.
- Playback depends on TikTok embed availability, network, region, and browser restrictions.
- Videos use TikTok's official embedded player. No view inflation, automatic refresh, or automatic looping.
- Links are processed in-browser; only theme preference is saved locally.
- Embeds connect to TikTok, and the stylesheet loads optional Google Fonts (system fallback available).
- This is an independent tool, not affiliated with TikTok. No advertising or analytics is installed. Ad approval is not guaranteed.
